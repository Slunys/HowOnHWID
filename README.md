# Поддерживаемые приложения

В данном репозитории представлена информация о поддержке различных приложений. Для удобства они разделены по операционным системам.

> [!IMPORTANT]
> **Обратите внимание:** В некоторых приложениях функция (HWID) отключена по умолчанию. Для их работы вам нужно зайти в настройки приложения и **включить её вручную**.

---

## 💻 Настольные ОС (Windows / macOS / Linux)

### Работают сразу:
* **Forks by Remnawave community**
* **Koala Clash** *(модификация Clash Verge Rev)*
* **FlClashX** *(модификация FlClash)*
* **DeskBox**

### Требуется настройка:
* **Throne** — ⚠️ *HWID отключен по умолчанию. Включите его в настройках.*
